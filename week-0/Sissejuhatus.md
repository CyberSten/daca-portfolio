-- Week 0 – Getting Started with Data Analytics --

**Overview**

My first week at Schooling was focused on setting up my data analytics environment and getting familiar with the tools I will be using throughout the DACA (Data Analyst Career Accelerator) programme.

It was a week of learning, installation, configuration and taking my first steps into SQL and data analysis.

**Tools and Environment Setup**
During Week 0, I installed and configured the following tools:
Supabase – Set up a PostgreSQL database project to work with data.
GitHub – Created and organised my learning portfolio to store SQL exercises and project files.
Visual Studio Code (VS Code) – Set up my code editor for working with SQL and Python.
SQLTools – Installed the extension and connected VS Code to my Supabase database.
Python – Installed Python and checked that it was working.
Power BI – Installed the tool for future data visualisation and reporting exercises.

**Supabase and SQL Practice**
I created my first database table, team_members, and practised inserting, viewing and managing records.
I also started working with the UrbanStyle.ltd training database.
I successfully created the database structure containing eight tables:
products
customers
sales
web_logs
inventory
inventory_movements
suppliers
promotions

I learned how database tables are structured and how primary keys and relationships connect different tables.

**GitHub Portfolio**
I created my DACA portfolio repository: "github.com/CyberSten/daca-portfolio" 
I learned how to organise project files, save SQL scripts, commit changes and push my work to GitHub.
My first SQL file was hello_urbanstyle.sql.

**What I Learned**
Week 0 helped me understand how the different tools fit together in a data analyst's workflow.
I now have a working development environment and have taken my first steps in database management and SQL querying.
There is still a lot to learn, but the foundation is in place.
